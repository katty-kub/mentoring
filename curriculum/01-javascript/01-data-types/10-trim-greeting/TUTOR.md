# Tutor: trim greeting

## Ladder

- "What is the computer seeing that you don't? Print the name between two | signs."
- "Is there a string method that removes spaces at the ends? Search MDN."

## Typical mistakes

- Typing "Ada" by hand. Ask: what if the name changes?
- Removing all spaces, inside too. Try "  Ada Lovelace  ".

## What if

- How many characters does the name have before and after? Look up `.length`.

## Tips

- Template literals (backticks) put values into text without `+`.
