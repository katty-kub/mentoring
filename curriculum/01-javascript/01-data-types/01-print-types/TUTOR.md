# Tutor: print types

Her question: "Which data types are used most in practice?"

In practice: string (names, form fields, URLs), number (prices, counts), boolean (isAdmin, isOpen).
Arrays start in print-all. Modules 05–06 go deeper on arrays and objects. null and undefined: task null-or-undefined.

## Ladder

- "Is there a word in JavaScript that tells you a value's type? Search MDN for 'type of'."
- "How do you print something? Can you put that word inside it?"

## Typical mistakes

- `typeof(age)` with brackets. Works. Fine.
- Printing the value instead of its type. Ask: "What did the expected output say?"

## What if

- What is the type of `"34"`? Change `age` and run.

## Tips

- Form fields are always text, even when someone types 42.
