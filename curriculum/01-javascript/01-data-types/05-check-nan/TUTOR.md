# Tutor: check NaN

Her first `if`. Conditions get their own module (02) later.

## Ladder

- "Convert first, like in text-to-nan. What value do you get for "abc"?"
- "Try `console.log(NaN === NaN)`. What prints?" → "Search MDN: 'Number.isNaN'."

## Typical mistakes

- `if (number === NaN)`. Always false. Let her see it print the NaN instead of "invalid".
