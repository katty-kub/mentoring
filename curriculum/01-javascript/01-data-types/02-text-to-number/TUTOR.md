# Tutor: text to number

## Ladder

- "Try `a + b` first. What printed? What type are `a` and `b`?"
- "Is there a way to turn text into a number? Search MDN: 'convert string to number'."

## Typical mistakes

- `a - -b` or `a * 1` tricks. Work, but ask: "Will someone reading it understand?"

## What if

- What if `a` is `"abc"`? What prints?

## Tips

- `Number()` says what it does. Tricks like `a * 1` hide it.
