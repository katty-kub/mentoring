# Tutor: merge lists

Her question: "How do I join two lists without changing them?"

## Ladder

- "In spread-predict, which line joined two lists? What did it print?"
- "You need a new list. What do you write first, to make a new list?"
- "Where does morning go in it? Where does afternoon go?"

## Typical mistakes

- `[morning, afternoon]`. Prints a list of two lists. Ask: count the `[` in the output.
- Writes the 4 words by hand. Ask: what if morning gets a new task tomorrow?
- Uses `concat`. It works. Ask her to write it with `...` too, then pick one.

## What if

- Put `"lunch"` between morning and afternoon. Still one line?
- Print morning after your code. Is it still 2 items?

## Tips

- A new list leaves the old ones as they are. Teams like that: nothing changes behind your back.
